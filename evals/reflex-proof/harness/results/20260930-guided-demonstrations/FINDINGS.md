## Where the integration stops

A read-only audit with the existing `adage-learn` ledger example reproduced one selected reflex,
zero compiled routes and zero execution contexts. This is upstream of certificate judgment:

1. Mining closure absorbs a shorter continuation into an equally supported longer continuation.
   All 70 scored patterns targeting pytest also include a subsequent Python-c action; no
   standalone pytest continuation survives. See `adage-graph/src/mine/closed.rs`, `mark`.
2. Only closed patterns reach scoring (`adage-graph/src/select.rs`, `learn_split`). Of the 70,
   48 fail contrast. Last-edit examples have support five but contrast 0.0909, below 0.3.
   The other 22 pass scoring without producing a route.
3. Execution-candidate recognition in `adage-graph/src/score.rs` requires a single continuation
   action and does not bypass the earlier contrast gate. Advisory discrimination therefore
   removes common routines before their execution eligibility can be assessed.
4. `adage-learn/src/engine.rs` reports zero compiled routes before `judge` runs. The visible
  Python-c compiler rejections do not mean pytest was rejected by its execution certificate.

[mining-diagnosis.json](mining-diagnosis.json) preserves all 70 pytest-target patterns and their
gates. [mining-diagnosis-provenance.json](mining-diagnosis-provenance.json) records the exact
read-only command, diagnostic binary hash, input hashes and complete local output hash.

There is a separate evidence limitation: five eventual command successes are not five successes
after one common trigger. In Unique, pytest initially fails and another edit intervenes. In
StartsWith, a scoped verification succeeds before the prescribed command. The existing execution
recount stops at these boundaries. That particular last-changelog-edit trigger can support at
most three sessions, below five. Fixing mining alone would not prove this cohort qualifies.

## Next bounded implementation experiment

Preserve independently certifiable single-action continuations before closure and advisory
contrast discard them, using the existing miner/compiler and execution recount. Keep directive
selection separate from execution eligibility: an action being common does not make advice
useful, but it can make automatic execution predictable. Do not relax support, failure boundaries,
command validation or human grants to obtain a positive result.

First add a regression with five guided-shaped histories containing an eligible edit-to-test
prefix followed by another action. It should retain the executable prefix without adding advice.
Counterexamples must still reject interrupted, failed, ambiguous and insufficiently supported
prefixes. Replay these five frozen real histories into a new output directory with new binary
hashes; retain this original zero-candidate checkpoint unchanged. Only after a genuinely eligible
candidate exists should a separately frozen, human-approved held-out execution study spend more.
