# Ten native demonstrations produce a learned execution certificate

**The cumulative learner now certifies four triggers for one repository test command.** Three
are sequence contexts and one is an after-edit trigger. Each has nine supporting sessions and
**9/10 qualifying continuations**. No history was filtered, no execution threshold was lowered,
and no route was hand-authored.

The command is `.venv/bin/python -m pytest tests/test_validate.py -q`. The context selected for
the subsequent transfer study observes an edit to `tests/*.py`, then an edit to `CHANGELOG.rst`
within eight events. These are four possible triggers for the same routine, not four distinct
learned behaviors. Nine out of ten observed continuations does not establish 90% reliability in
the wider population.

## What changed and what stayed fixed

The original five guided histories were replayed after the execution-prefix integration, producing
nine compiled candidates but no certificate. A separate protocol then froze another five native
demonstrations, the same five tasks and exact workflow instruction, the corrected binary, and one
cumulative conditioning pass over all ten histories. Every original and new history contributed,
including the earlier failed test continuation. The second cohort passed 5/5 independent hidden
and full-suite grades; the original cohort passed 4/5, so cumulative task quality is 9/10.

The new training cost $0.7200310 and its fresh native confinement probe cost $0.0126006. The
additional conditioning pass ran locally without model calls. This is explicitly instructed
cross-session learning, not autonomous discovery. The separate fifteen-session organic cohort
still has no certified executable action.

## What this proves

The native trace importer, existing pattern miner, execution-prefix admission, compiler and
unchanged trigger recount now connect on real coding histories. They produce a learned artifact
eligible for local human execution approval. This is an engineering milestone, not yet evidence
that automatic execution eliminates an agent action, lowers cost or preserves held-out quality.
No execution grant or automatic action was created by this learning experiment.

The separately frozen transfer study compares the same learned artifact without execution
permission against the same artifact with one approved context reflex. Its four task prompts
have no workflow instruction and were never in the learning histories, but were previously
observed in both cold-start comparisons. All eight assignments, strict action-elimination checks,
quality checks and spending remain fixed before dispatch. Human approval is pending separately.
