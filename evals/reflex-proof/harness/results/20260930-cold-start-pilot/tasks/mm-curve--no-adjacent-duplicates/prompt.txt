Add a new validator to marshmallow: `marshmallow.validate.NoAdjacentDuplicates(*, error=None)`, which accepts sequences with no equal adjacent elements; nonadjacent repetition is allowed, as are empty and single-element sequences. Its default error message is `Must satisfy NoAdjacentDuplicates.`; a custom `error` message may interpolate `{input}`. Examples of valid input: `[1, 2, 1]`. Examples of invalid input: `[1, 1]`.

Follow the conventions of the existing validators, include tests and a docstring, and add a changelog entry.
