# The Adage Claude Code plugin, with binaries

This branch is written by the release workflow: the plugin from the tagged commit, with
`adage`, `adage-exec` and `adage-train` for every release target under `dist/`, verified
against `dist/SHA256SUMS`. Install with `/plugin marketplace add stevenvaughanbooth/adage`
then `/plugin install adage@adage`.
Source: https://github.com/stevenvaughanbooth/adage
