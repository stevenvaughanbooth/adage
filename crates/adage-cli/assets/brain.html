From demo to your repository

Set up your first repository.

Use the terminal command palette for setup. Choose each action by name; there are no shell commands to copy between these steps.

01 / WORKSPACE

Open your repository

In the Adage terminal app, press Ctrl K or :. Choose Open a repository and enter its folder.

New to this checkout? Build and launch Adage once using the README’s “Try this checkout” instructions. Published installers are not available yet. You can keep exploring this demo before installing.

02 / CONNECT

Connect your coding tool

Choose Connect Claude Code, Connect Codex, or Connect OpenCode. Review the hook changes before accepting.

Codex requires its own hook approval. In Codex, open /hooks to accept the registration, then start a coding session. Health distinguishes registered hooks from a hook actually received.

03 / HISTORY

Choose what Adage learns from

Claude Code and Codex history are detected automatically. Use Configure Claude Code history or Configure Codex history to choose a different folder.

For OpenCode, choose Import OpenCode history to bring in recent sessions from this repository. You can also choose an existing folder with Configure OpenCode history.

04 / LEARN & REVIEW

Learn, inspect, then observe

Choose Learn from this repository. Review the detected sources and usable session count before learning. Open Review learned reflexes to inspect triggers, responses, and proposed changes.

Choose Open the web map to return here with your data. Outcome counts link to their contributing traces. Quiet activity can mean that no reflex applies yet.

Help & controls

Explore here. Take action in the terminal app. Both surfaces use the same local Adage workspace.

Manage Adage without memorizing commands

  1. Open the Adage terminal app. If you arrived through the standalone demo, start with Set up your first repository.
  2. Open the command palette with Ctrl K and search for what you want to do.
  3. Choose an action such as Open a repository, Learn from this repository, Review learned reflexes, or Health and setup.
  4. Choose Open the web map in the palette, or press w in the terminal app, whenever you want this view.

Keep the terminal app open while using the dashboard it launched. If the connection stops, reopen the dashboard from that app. This page reconnects automatically.

What you can do here

  • Explore reflexes, including nascent and extinguished responses.

A few useful terms

Reflex
A situation paired with guidance for the agent’s next step.
Instinct
A planned built-in response detected from repository files. Instincts are not available in this build.
Track / pack
Tracks store responses on disk. Packs are the signed collections you review and share.
In service
A firm or forming reflex included in the compiled index.
Nascent
A reflex waiting outside active service, often for review.
Control
A session where Adage withholds guidance to observe the baseline.
Strength
Fire: do this. Prime: consider this. Inhibit: avoid a known dead end.
