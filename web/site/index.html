What actually moves off the model?

By default: local CPU matching delivers guidance; supported pre-call instincts can correct a command to the repository's verified environment without another model request. The agent still executes its tools.

With separate execution approval: adage-exec can prefetch a read-only result or run a staged action in a sandbox and apply permitted outputs. Choosing and running that invocation needs no model request; the agent may still reason over its result.

A learned command is not automatically approved to run. A delivered directive is not proof of a saved model turn. Each behavior has its own evidence.

How it works

Your agents already wrote the manual. Adage reads it.

  1. 01

    Read the traces

    Claude Code leaves a transcript of every session, and Adage reads it where it already is, on your machine. There is nothing to instrument. Codex and OpenCode adapters are in preview.

  2. 02

    Condition reflexes

    After each session, one learner keeps the steps that got work done and compiles them into reflexes: small, typed rules with their evidence attached. Dead ends become inhibit reflexes, and a task the repository keeps repeating gets a procedure card.

  3. 03

    Deliver at the hooks

    When the same moment comes back, a hook matches it and hands the agent a one-line directive. The model still decides; it just doesn't have to rediscover the repository.

Every reflex carries its evidence. Advice is weighed by uplift: how much more often agents take the step when told than on their own. A recurring edit-then-command routine can instead become an execution candidate, even when a reminder adds no value. It stays silent until a person approves its exact automatic action.

Packs

Share what your agents learned. Get instincts on day one.

A skill is a page of instructions your agent has to read. A reflex is a small rule Adage matches for it, with its evidence attached. Reflexes travel as packs: a folder of plain text files, signed, that a teammate installs with one command. Adage's built-in instincts are packs too.

The label on the box: its name and version, where it applies (one repository here), what it needs, and the most it may ever ask to run (E0: advice only).

format = "adage-pack/1"

[pack]
name = "acme-billing/work-items"
version = "0.1.0"
origin = "reflex"
description = "Context gathering for prompts that name a work item"

[applicability]
kind = "repo"
repo_keys = ["acme-billing"]

[requires]
harness = ["claude-code"]
templates = ["read@1"]

[exec]
requested = "E0"

[provenance]
tool = "adage 0.1.0"

[provenance.origins]
organic = 3
synthetic = 0
declared = 0
instinct = 0
imported = 0
As Adage filled them in for a Python project with a .venv.

Real files. The reflex pack is one Adage learned in a study (acme-billing, Claude Sonnet 5) and shared with adage share, signed with a throwaway test key; the instinct is Adage's own packs/python-env, exactly as its marketplace pins it.

  1. 01 / share

    Package it

    One command builds the pack, checks every byte for secrets and machine paths, and signs it with your SSH key.

    adage share work-items --out packs/work-items
  2. 02 / add

    Hand it over

    Your teammate's Adage checks the signature, works out what the pack depends on and re-checks every command before it installs anything.

    adage add packs/work-items
  3. 03 / bind

    It binds where it fits

    Each pack says where it applies: its own repository, or any repository whose files match. Shared reflexes start as suggestions, and a reflex learned on that machine always wins.

    adage packs

Instincts come in the box

Adage's own repository is its first marketplace: eight instinct packs, each pinned by its digest, the way a Claude Code marketplace lists plugins. Every copy of Adage carries it, so nothing is downloaded. Each pack names a detector that reads your repository's files (Makefile, package.json, pyproject.toml, lockfiles) and turns on only where it finds what it needs. Nothing runs, and a reflex Adage learns from your own work replaces it.

  • adage/python-envRun tests inside the project's Python environment.
  • adage/test-wrapperUse the test target that sets what the tests need.
  • adage/test-commandUse the repository's one declared test command.
  • adage/pytest-wrapperRun pytest the way the repository runs it.
  • adage/package-managerUse pnpm, yarn or bun where the repository says so.
  • adage/regenerateRegenerate after editing a generator's inputs.
  • adage/generated-filesDon't hand-edit generated files.
  • adage/lockfilesDon't hand-edit lockfiles.

See the marketplace with adage marketplace, which packs apply with adage packs, and turn any off with adage packs off adage/lockfiles.

A pack is trusted one of two ways: an SSH signature from someone you trust, or a digest pinned by a marketplace you trust (Adage's own, for its instincts). Where it is stored doesn't matter. Commit it to your repository, send the folder, or keep a team marketplace in a git repository. Adding a marketplace by name comes next.

Published with their caveats. The two sandbox runs reused round 1's work items in round 2, fixed the arm order and shared the operator's auto-memory, so treat them as indicative until they are repeated under the stricter protocol. The card intervals are 90% bootstrap intervals clustered by task; with 6–12 tasks per comparison, read them as closer to 80%. On one-off bug fixes the effect is small: the .venv instinct took the system-Python dead end from 5 of 6 sessions to 0 of 6, and every lever a hook can pull was worth 0–4% of cost. Every install keeps about one session in ten as a control, and adage savings states what Adage saves on your own work only once 10 control and 30 treated sessions have finished.

Built to stay out of the way

It speaks up only when it matches. Otherwise it isn't there.

  • Your agent keeps control

    By default, your agent executes the suggested steps through its own tools and permissions. One change is on by default in Claude Code: a Python test run under the system Python is pointed at the project's verified .venv, shown to you each time; adage delegate rewrites off turns it off. Delegating a step is opt-in, per reflex, inside an OS sandbox.

  • Fails open

    If Adage errors or runs out of time at a hook, the agent carries on as if it were not installed.

  • Evidence attached

    Every reflex carries its distinct sessions, a Wilson lower bound and its uplift, what telling the agent changes. Review any of them, then strengthen, weaken or extinguish it.

  • Yours, on disk

    Traces stay on your machine. Reflexes live in tracks on disk and travel as signed packs you can review, commit and share.

Get started

Install the plugin. Start a session.

When the first release ships, install the Claude Code plugin and start a session in a repository. Adage binds instincts and learns from earlier traces in the background. The plugin bundles its binaries; it does not put adage on your terminal's PATH.

Have repository access? Build the CLI from source, then try the isolated demos below. The source preview currently requires access to the private repository. Homebrew and @adage-sh/cli distribution are planned for the release. Codex and OpenCode adapters are in preview.
