How it works

Your agents already wrote the manual. Adage reads it.

  1. 01

    Read the traces

    Claude Code leaves a transcript of every session, and Adage reads it where it already is, on your machine. There is nothing to instrument. Codex and OpenCode adapters are in preview.

  2. 02

    Condition reflexes

    After each session, one learner keeps the steps that got work done and compiles them into reflexes: small, typed rules with their evidence attached. Dead ends become inhibit reflexes, and a task the repository keeps repeating gets a procedure card.

  3. 03

    Deliver at the hooks

    When the same moment comes back, a hook matches it and hands the agent a one-line directive. The model still decides; it just doesn't have to rediscover the repository.

Every reflex carries its evidence and is weighed by uplift: how much more often agents take the step when told than on their own. A reflex under +0.1 stays quiet until you approve it in adage review.

Published with their caveats. The two sandbox runs reused round 1's work items in round 2, fixed the arm order and shared the operator's auto-memory, so treat them as indicative until they are repeated under the stricter protocol. The card intervals are 90% bootstrap intervals clustered by task; with 6–12 tasks per comparison, read them as closer to 80%. On one-off bug fixes the effect is small: the .venv instinct took the system-Python dead end from 5 of 6 sessions to 0 of 6, and every lever a hook can pull was worth 0–4% of cost. Every install keeps about one session in ten as a control, and adage savings states what Adage saves on your own work only once 10 control and 30 treated sessions have finished.

Built to stay out of the way

It speaks up only when it matches. Otherwise it isn't there.

  • Never runs a command for you

    Your agent runs every step through its own tools, under its harness's permissions. One change is on by default in Claude Code: a Python test run under the system Python is pointed at the project's verified .venv, shown to you each time; adage delegate rewrites off turns it off. Delegating a step is opt-in, per reflex, inside an OS sandbox.

  • Fails open

    If Adage errors or runs out of time at a hook, the agent carries on as if it were not installed.

  • Evidence attached

    Every reflex carries its distinct sessions, a Wilson lower bound and its uplift, what telling the agent changes. Review any of them, then strengthen, weaken or extinguish it.

  • Yours, on disk

    Traces stay on your machine. Reflexes live in tracks on disk and travel as signed packs you can review, commit and share.

Get started

Install the plugin. Start a session.

In Claude Code, two commands install Adage with its binaries verified, so nothing else is downloaded. At the first session in a repository, Adage binds its instincts and learns from that repository's earlier sessions, and one line tells you so. Plain adage, in a terminal or as !adage in Claude Code, prints where things stand. For Codex and OpenCode, install the binary with Homebrew or npm and run adage install codex or adage install opencode. The first release is on its way; early access gets it first.
