What actually moves off the model?

By default: local CPU matching delivers guidance; supported pre-call instincts can correct a command to the repository's verified environment without another model request. The agent still executes its tools.

With separate execution approval: adage-exec can prefetch a read-only result or run a staged action in a sandbox and apply permitted outputs. Choosing and running that invocation needs no model request; the agent may still reason over its result.

A learned command is not automatically approved to run. A delivered directive is not proof of a saved model turn. Each behavior has its own evidence. Adage saves model calls by handling learned reflexes and instincts on your CPU; we count that in model requests, tokens and API cost. GPU use and energy are not measured. How we tested it →

How it works

Your agents already wrote the manual. Adage reads it.

  1. 01

    Read the traces

    Claude Code leaves a transcript of every session, and Adage reads it where it already is, on your machine. There is nothing to instrument. Codex and OpenCode adapters are in preview.

  2. 02

    Condition reflexes

    After each session, one learner keeps the steps that got work done and compiles them into reflexes: small, typed rules with their evidence attached. Dead ends become inhibit reflexes, and a task the repository keeps repeating gets a procedure card.

  3. 03

    Deliver at the hooks

    When the same moment comes back, a hook matches it and hands the agent a one-line directive. The model still decides; it just doesn't have to rediscover the repository.

Every reflex carries its evidence. Advice is weighed by uplift: how much more often agents take the step when told than on their own. A recurring edit-then-command routine can instead become an execution candidate, even when a reminder adds no value. It stays silent until a person approves its exact automatic action.

Built to stay out of the way

It speaks up only when it matches. Otherwise it isn't there.

  • Your agent keeps control

    By default, your agent executes the suggested steps through its own tools and permissions. One change is on by default in Claude Code: a Python test run under the system Python is pointed at the project's verified .venv, shown to you each time; adage delegate rewrites off turns it off. Delegating a step is opt-in, per reflex, inside an OS sandbox.

  • Fails open

    If Adage errors or runs out of time at a hook, the agent carries on as if it were not installed.

  • Evidence attached

    Every reflex carries its distinct sessions, a Wilson lower bound and its uplift, what telling the agent changes. Review any of them, then strengthen, weaken or extinguish it.

  • Yours, on disk

    Traces stay on your machine. Reflexes live in tracks on disk and travel as signed packs you can review, commit and share.
