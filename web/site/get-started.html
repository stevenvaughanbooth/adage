Get started

Install it. Explore it. Then try your own history.

Find the useful lessons in your agent's history. Try Adage on a repository or workflow you know well, inspect the reflexes it learns, and help us discover patterns worth reusing.

Install @adage-sh/cli from npm with the command shown here. It downloads prebuilt binaries for your platform; you do not need Rust or a repository clone. GitHub release downloads and a Claude Code plugin are also available.

With Node.js 18 or later and npm installed, the command sets up Adage and its companion binaries. Try a sample-data demo, then run adage init in a project to review setup. Claude Code is the primary integration; Codex and OpenCode are in preview.

Prebuilt binaries support macOS, Linux and Windows. Opt-in execution is experimental and runs in an operating-system sandbox on macOS and Linux. Windows supports advice, not command execution.

Standalone downloads · no Node.js required

Get the v0.1.0 GitHub release for macOS, Linux or Windows. On macOS or Linux, the shell installer below installs adage. Follow any PATH instructions it prints, then run adage init in your project; it offers to fetch matching companion binaries and checks their published checksums. On Windows, download the CLI archive from the release page.

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/stevenvaughanbooth/adage/releases/download/v0.1.0/adage-cli-installer.sh | sh
Build from source · requires Rust and Git

Prefer a source build? From your checkout: cargo install --locked --path crates/adage-cli. Or install from Git:

cargo install --locked --git https://github.com/stevenvaughanbooth/adage adage-cli

For a real repository, run adage init. To connect Codex or OpenCode (preview integrations), run adage install codex --write --scope user or adage install opencode --write --scope user. These commands apply the hook setup; omit --write to print it first. Run adage doctor to verify setup.

Claude Code plugin

Install inside Claude Code with the two commands below. The plugin bundles Adage but does not add its CLI to your terminal PATH. Use npm or a standalone download if you also want the commands and demos above.

/plugin marketplace add stevenvaughanbooth/adage
/plugin install adage@adage
