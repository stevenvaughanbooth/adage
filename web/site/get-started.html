Get started

Install it. Explore it. Then try your own history.

Adage is an experiment in learning repeatable steps from coding agent sessions. The first public release is being prepared. The npm package and release downloads below are the planned install paths; they are not published yet.

Once released, the npm launcher installs prebuilt Adage binaries. You will not need Rust or a repository clone. Start with a sample-data demo, then run adage init in a project to review setup. Claude Code is the primary integration; Codex and OpenCode are in preview.

macOS and Linux are the initial download targets. Opt-in execution is experimental and runs in an operating-system sandbox. Windows execution is unsupported.

Look under the hood

See every reflex. Follow its evidence.

After installing, try any of these local demos. They use sample histories in temporary storage and leave your real Adage data alone.

01 / beside your agent

The live pane

Keep a small terminal split open. See hooks and reflexes as they happen.

adage watch --demo
02 / keyboard first

The control room

Inspect reflexes, review evidence, check health. Navigate without leaving the terminal.

adage ui --demo
03 / the whole picture

The local map

Follow traces into reflexes in your browser. Read-only, served by the binary on localhost.

adage map --demo
Source preview · requires repository access, Rust and Git

Already have repository access? From your checkout: cargo install --locked --path crates/adage-cli. Or install from Git:

cargo install --locked --git https://github.com/stevenvaughanbooth/adage adage-cli

For a real repository, run adage init. Preview harness setup: adage install codex --write --scope user or adage install opencode --write --scope user. Run adage doctor to verify setup.

Claude Code plugin · after the first release

The plugin bundles Adage with Claude Code. It does not add the CLI to your terminal PATH, so use npm if you also want the commands and demos above.

/plugin marketplace add stevenvaughanbooth/adage
/plugin install adage@adage
