Get started

Not released yet. The plugin comes first.

Adage is an unreleased developer preview. Nothing is published yet: no plugin marketplace, release binaries, Homebrew tap or npm package. When the first release ships, install the Claude Code plugin and start a session in a repository. Adage binds instincts and learns from earlier traces in the background. The plugin bundles its binaries; it does not put adage on your terminal's PATH.

Have repository access? Build the CLI from source, then try the isolated demos below. The source preview currently requires access to the private repository. Homebrew and @adage-sh/cli distribution are planned for the release. Codex and OpenCode adapters are in preview. Opt-in execution runs on macOS and Linux; Windows execution is unsupported.

Look under the hood

See every reflex. Follow its evidence.

One local system, three ways in. The demos use sample traces in temporary storage and leave your real Adage data alone.

01 / beside your agent

The live pane

Keep a small terminal split open. See hooks and reflexes as they happen.

adage watch --demo
02 / keyboard first

The control room

Inspect reflexes, review evidence, check health. Navigate without leaving the terminal.

adage ui --demo
03 / the whole picture

The local map

Follow traces into reflexes in your browser. Read-only, served by the binary on localhost.

adage map --demo
Source preview · requires repository access, Rust and Git

Already have repository access? From your checkout: cargo install --locked --path crates/adage-cli. Or install from Git:

cargo install --locked --git https://github.com/stevenvaughanbooth/adage adage-cli

For a real repository, run adage init. Preview harness setup: adage install codex --write --scope user or adage install opencode --write --scope user. Run adage doctor to verify setup.
