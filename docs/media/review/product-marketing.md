## Verdict

The film sells a mechanism with real footage and real numbers but never states the category, so this audience will file it as "another agent memory tool" and ask why not four lines in CLAUDE.md. The giant numbers at 66–71 s lead with a proxy (10× on turns-before-first-edit) and end with the one result the README marks not significant (100% checks, p = 0.11, n = 18), which an investor will look up. The reflex/instinct primitives fix both: they name the category, answer the cold-start objection the film creates at 50 s, and give the compute section its line.

## Top findings

1. **No one-sentence positioning (0–26 s).** As stated: "Your agent forgets everything. Adage records it. Then predicts it. Put your agent on rails." "Predicts" is wrong (it directs, deterministically); "records" reads as memory. Fix: 17.3 s becomes "Then it's a reflex."; the working line goes under the wordmark at 21.4 s.
2. **Cold start is raised, never answered (50 s "Mined from 54 sessions").** Viewers conclude nothing happens until they have 54 sessions. Instincts are the answer and are absent. Fix: "Ships with instincts. Learns reflexes." at 21 s and 74 s, if instincts ship.
3. **68.5 s "100% hidden checks passed · up from 78%" is n.s. per README.** Fix: replace with the dead-end result ("1.44 failed pytest runs per session → 0"), a learned reflex and a real effect, or show "n = 18" and run it last.
4. **66 s "10×" is a proxy; 68.5 s "−61% cost per task" is what leaders pay for; total turns 9 vs 27.5 never appears.** Fix: order −61%, 3× fewer turns, then quality.
5. **59 s mixes units: "28 model turns per task … $0.135 per task" beside "5 ms per decision · $0 of inference".** Reads as inference going to zero; the agent still ran 9 model turns. Fix: "5 ms per reflex · $0 per reflex" plus "the novel work still runs on the model".
6. **Numbers disagree across beats.** Turns: 24 (44.5 s), 20 (66 s), 28 (56 s). Sessions: 14 (10 s), 54 (50 s). "Under 6 ms" (27 s) vs "5 ms · CPU" (33 s). 55 s "No model." while the 27 s init panel shows an "Embedding model" step. Fix: label each turn figure by kind, "5 ms" everywhere, "No model in the loop".
7. **79 s chips overclaim.** "Claude Code · OpenCode · Codex": README says both adapters are unverified live; the 27 s panel shows "opencode not found · codex not found". "Signed releases · SBOM · provenance" with no tagged release. Fix: "Claude Code today · OpenCode, Codex next"; drop the signing chip.
8. **79 s CTA is an install, not an action.** Fix: add "adage survey — read-only" and the results URL.
