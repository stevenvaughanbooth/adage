## What Adage is (facts you can rely on)

- One Rust binary (`adage`, ~10 MB, no daemon), Apache-2.0, `brew install stevenvaughanbooth/tap/adage && adage init`.
- It wires itself into a coding agent harness through the harness's hooks (Claude Code today: SessionStart, UserPromptSubmit, PostToolUse, Stop, SessionEnd; OpenCode and Codex adapters planned/partial). Each hook call costs ~5 ms wall / 10 MB RSS. Fail-open: if Adage errors, the agent proceeds normally.
- It records what the agent did (the harness transcripts), then `adage learn` mines them for **routes**: repeatable steps that earlier sessions took toward finishing a task. A route has a trigger (on prompt matching a pattern, after a command, after an edit of certain paths, at session start), a step (run a command, read files together, avoid a command), evidence (support N of M sessions, rate, lower bound, turns saved), and an aspect: green (do this), yellow (consider), red (dead end: avoid this, do that instead). Routes are grouped in tracks (`acme-billing/work-items@0.1.0`). Routes are text injected into the agent's context as `<adage-signal>` blocks; Adage never executes anything itself. Deterministic: no model in the loop at decision time. Learning is also model-free ("no model" in the status line; an optional embedding model enables intent families).
- Auto-learn: after sessions end it re-learns; routes gain/lose evidence and can change aspect. `adage watch` is a live TUI showing hook events and what fired. `adage graph --serve` is a browser "signal box" showing the graph. `adage share` / `adage add` exchange tracks between repos/teams.
- Measured (18 tasks with Adage vs 18 without, Claude Haiku 4.5, demo repo "acme-billing"): median turns before first edit 2 vs 20; seconds to first edit 12.0 vs 42.5; cost per task $0.053 vs $0.135; hidden checks passed 100% vs 78%. Learning 54 sessions took 0.24 s. Those 54 training sessions cost $4.87 / 949 turns of inference.
- The film's session is a real recorded one: task W-2045 ("Can you take care of W-2045?"), Claude Haiku 4.5. With Adage: first edit at turn 4, 9 turns total, commit f247fa1. The same task without Adage in the same round: first edit at turn 24, 30 turns. Routes that fired: lookup-work-item (green, 23/33 sessions, 8 turns saved), read-linked-files (yellow, 15/16), finish-line-e7e809 (green, 7/7, "make gen after editing schema/*.json"), dead-end-d41b1e (red, "pytest fails here, use make test").

## The new brand primitives (decided, not up for debate; the film has NOT been updated to them yet)

- **Reflexes**: routes Adage *learned* from this repo's recorded sessions, with evidence. `adage learn` learns reflexes. A dead end is a reflex too (flinching away from pytest).
- **Instincts**: routes Adage *ships with* (or curated packs you install). They work with zero history, on day one.
- Shared tracks: a reflex someone else learned, adopted as your instinct.
- Working line: "Ships with instincts. Learns reflexes." Compute line: "Reflexes skip the brain. Known routes skip the GPU." Both words are lowercase feature nouns, never sub-brands (AMD Instinct and the Instinct AI-assistant startup, and Pynecone's REFLEX mark, exist; we use these words descriptively).

## Audience and goal

The film opens a live pitch to technical people (developers who run coding agents daily, engineering leaders who pay the inference bill, and investors who understand dev tools). It must make them want to install it and to believe the numbers. Exceptional, not adequate.
